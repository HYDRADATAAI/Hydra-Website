# Release and audit history

This directory contains historical HYDRA website release material that is no
longer part of the active recruiter-facing root:

- changelogs and build reports;
- verification snapshots and release seals;
- recruiter/audit matrices;
- deployment and discovery helpers;
- claim/proof authority maps;
- packaging manifests and patch notes.

The files are retained for traceability and engineering history.

Current public reviewers should use the root `README.md`, live site pages,
`docs/`, and `evidence/`.
